# Security Policy

## Reporting a Vulnerability

If you have a vulnerability to report, please follow [our responsible disclosure policy](https://www.notion.so/Responsible-Disclosure-Policy-421a6a3be1714d388ebbadba7eebbdc8).

You can also use [GitHub's private vulnerability reporting](https://github.com/serversideup/benchkit-laravel/security/advisories/new) on this repository.

## Supported versions

Fixes land on the latest release. BenchKit instances are meant to be temporary, so pull the current image rather than patching an old one.
