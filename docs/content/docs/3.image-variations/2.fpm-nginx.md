`fpm-nginx` is the **default** BenchKit image. It runs PHP-FPM behind nginx, which is what the vast majority of Laravel applications run in production and the right baseline for any comparison.

## Run it

```bash [Terminal]
docker run -p 80:8080 \
  -v benchkit-runs:/var/www/html/storage/app/runs \
  serversideup/benchkit-laravel
```

That's the same as pulling `serversideup/benchkit-laravel:latest`, whose default variation is `fpm-nginx`.

## Tuning the pool

FPM's pool size matters for throughput and is worth setting to match your box:

```yaml [compose.yml]
environment:
  - PHP_FPM_PM_CONTROL=dynamic
  - PHP_FPM_PM_MAX_CHILDREN=20
```

::note
BenchKit records the FPM pool config (`pm`, `pm.max_children`) when it can detect it, and flags any load test that asked for more concurrency than the pool can serve. An FPM-versus-worker comparison is only fair between tuned pools. See [Customizing the image](/docs/configuration/customizing-the-image).
::

## When to use it

Use `fpm-nginx` as your **baseline**. Run your suite here first, then run it on [`frankenphp`](/docs/image-variations/frankenphp) and compare the two.
