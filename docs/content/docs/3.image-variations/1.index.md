---
title: Choosing a variation
description: BenchKit ships the same application on three web servers. Pick one with the image tag.
---

BenchKit publishes one application in several image variations, each serving PHP with a different web server. The application is identical in all of them, so any difference between two runs comes from the server rather than from the code. The tag you pull decides which one you get.

Images are published to Docker Hub at [`serversideup/benchkit-laravel`](https://hub.docker.com/r/serversideup/benchkit-laravel) and to the GitHub Container Registry.

## At a glance

| Variation | How PHP is served | Tag |
| --- | --- | --- |
| [**FPM-NGINX**](/docs/image-variations/fpm-nginx) | nginx hands PHP requests to PHP-FPM | `latest` |
| [**FrankenPHP**](/docs/image-variations/frankenphp) | One binary serves PHP directly | `frankenphp` |
| [**FPM-Apache**](/docs/image-variations/fpm-apache) | Apache hands PHP requests to PHP-FPM | `fpm-apache` |

All three listen on port 8080 inside the container, serve from `/var/www/html/public`, and run as `www-data`.

## Comparing variations fairly

Run each variation on the same machine, one after the other, and compare the runs in **Compare**. Because the hardware and the application are identical, what is left is the serving model.

Two things will spoil that comparison if you let them:

**A stock FPM pool is a ceiling, not a measurement.** Under PHP-FPM a request occupies a worker for as long as it takes, so the pool size caps concurrency no matter how fast the hardware is. BenchKit flags a run where the pool was the limit.

**Neither side is tuned out of the box.** A stock pool against a stock FrankenPHP tells you about the defaults rather than about the servers. Compare tuned against tuned, and say which tuning you used.

::tip{to="/docs/configuration/customizing-the-image"}
Tune the pool before you compare. `PHP_FPM_PM_MAX_CHILDREN` is the one that matters most.
::

[Reading your results](/docs/benchmarks/reading-your-results) covers both in more depth.
