BenchKit is published in several **image variations**, each running a different PHP web-server stack. They all run the identical BenchKit application, so results are directly comparable — the only thing that changes is *how PHP is served*.

Images are published to Docker Hub at [`serversideup/benchkit-laravel`](https://hub.docker.com/r/serversideup/benchkit-laravel).

## The two you'll reach for

::card-group
  :::card
  ---
  title: fpm-nginx
  icon: i-simple-icons-nginx
  to: /docs/image-variations/fpm-nginx
  ---
  The classic PHP-FPM + nginx stack. The default image, and the baseline most Laravel apps run today.
  :::

  :::card
  ---
  title: frankenphp
  icon: i-lucide-zap
  to: /docs/image-variations/frankenphp
  ---
  Modern, container-native PHP. Run it in worker (Octane) mode to benchmark the new hotness.
  :::
::

## Other variations

Because BenchKit is built on [serversideup/php](https://serversideup.net/open-source/docker-php), other variations from that base (such as `fpm-apache`) are available too. The two above are the ones BenchKit documents and promotes, because they're the most instructive comparison: **the established default vs. the modern worker-mode runtime.**

::note
Pick the variation with the image **tag**. The default tag (`serversideup/benchkit-laravel`) is `fpm-nginx`; append `:frankenphp` for FrankenPHP.
::
