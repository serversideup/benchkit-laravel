[FrankenPHP](https://frankenphp.dev) is a modern PHP application server built for containers. Its headline feature is **worker mode** (via Laravel Octane): the framework boots once and stays resident, instead of bootstrapping on every request.

## Classic mode

The `frankenphp` image runs in classic (per-request) mode by default — directly comparable to `fpm-nginx`:

```bash [Terminal]
docker run -p 80:8080 \
  -v benchkit-runs:/var/www/html/storage/app/runs \
  serversideup/benchkit-laravel:frankenphp
```

## Worker mode (Octane)

To benchmark the worker model, start Octane with FrankenPHP — same image, just a different command:

```bash [Terminal]
docker run -p 80:8080 \
  -v benchkit-runs:/var/www/html/storage/app/runs \
  serversideup/benchkit-laravel:frankenphp \
  php artisan octane:start --server=frankenphp --host=0.0.0.0 --port=8080
```

Results are labeled with the mode that produced them (look for the **worker mode** badge), so shared results always say which mode was benchmarked.

## The lesson worth learning

Worker mode's win comes from **skipping the framework bootstrap**. That saving is large on CPU-bound, no-I/O routes — and shrinks toward zero once a request spends most of its time waiting on a database or network call.

::tip
Run the suite on `fpm-nginx` and on `frankenphp` worker mode, open both in **Compare**, then raise the **Simulated I/O response** and re-run. Watch worker mode's lead collapse as I/O grows. That convergence — not the hello-world number — is the real-world takeaway. See [Benchmarks & methodology](/docs/benchmarks/web-server-load-test).
::
