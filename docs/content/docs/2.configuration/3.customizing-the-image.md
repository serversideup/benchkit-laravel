---
title: Customizing the image
description: Tune PHP, OPcache, and the web server with environment variables.
---

BenchKit is built on the [serversideup/php](https://serversideup.net/open-source/docker-php) images, so it inherits their full set of environment-variable controls. That means you can tune the runtime **without rebuilding** — which is exactly what makes BenchKit a good playground.

## Common tuning knobs

```yaml [compose.yml]
services:
  benchkit:
    image: serversideup/benchkit-laravel
    environment:
      # OPcache (on by default in BenchKit)
      - PHP_OPCACHE_ENABLE=1
      - PHP_OPCACHE_JIT=tracing
      - PHP_OPCACHE_MEMORY_CONSUMPTION=256
      # PHP
      - PHP_MEMORY_LIMIT=512M
      # FPM pool (fpm-nginx / fpm-apache variations)
      - PHP_FPM_PM_CONTROL=dynamic
      - PHP_FPM_PM_MAX_CHILDREN=20
```

::tip{to="https://serversideup.net/open-source/docker-php/docs/reference/environment-variable-specification" target="_blank"}
The full list of supported variables lives in the serversideup/php **Environment Variable Specification**. Everything there works in BenchKit.
::

## Turn tuning into an experiment

Because these are just environment variables, you can run BenchKit twice with different settings and diff the results:

1. Run with a setting **off** (e.g. `PHP_OPCACHE_ENABLE=0`).
2. Run with it **on**.
3. Open both in **Compare** and read the delta.

The results **Environment panel** captures the `php.ini` values that were actually in effect, so you always know which knob produced the change.

## Web server variation

Which web server runs (nginx, Apache, or FrankenPHP) is chosen by the **image variation** you pull, not an environment variable. See [Image variations](/docs/image-variations).
