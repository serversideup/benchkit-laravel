---
title: Deployment options
description: Run the prebuilt Docker image, or clone the repository and run it yourself.
---

There are two ways to run BenchKit. For almost everyone, the **Docker image** is the right choice.

## Option 1: Docker image (recommended)

Pull and run the published image — no source code, no build step:

```bash [Terminal]
docker run -p 80:8080 \
  -v benchkit-runs:/var/www/html/storage/app/runs \
  serversideup/benchkit-laravel
```

The image is published to Docker Hub at [`serversideup/benchkit-laravel`](https://hub.docker.com/r/serversideup/benchkit-laravel) in several [variations](/docs/image-variations) (`fpm-nginx`, `frankenphp`, and more). It's designed to be **run and then destroyed** once you're done — it's a benchmarking tool, not a long-lived service.

::note
BenchKit is **not** a Laravel package you install into your app. It's a standalone application you run against your infrastructure.
::

## Option 2: Clone the repository

You can also run BenchKit from source — useful if you want to run it on a PaaS (Laravel Cloud, DigitalOcean App Platform, etc.) or contribute.

```bash [Terminal]
git clone https://github.com/serversideup/benchkit-laravel.git
cd benchkit-laravel
```

BenchKit depends on a few external tools for its benchmarks — [YABS](https://github.com/masonr/yet-another-bench-script) (hardware), [cfspeedtest](https://github.com/code-inflation/cfspeedtest) (network), and [oha](https://github.com/hatoo/oha) (web-server load). The Docker image bundles these for you; a from-source deploy needs them available on the host.

::tip
The local development stack (Docker Compose) bind-mounts the repo, so run history persists on your machine automatically — no volume needed. See [`CONTRIBUTING.md`](https://github.com/serversideup/benchkit-laravel/blob/main/CONTRIBUTING.md).
::

## Keeping your run history

Every completed run is saved as a snapshot in `storage/app/runs`. Mount a volume there to keep history across rebuilds — which is exactly what you need to compare image variations (e.g. `fpm-nginx` vs `frankenphp`) over time:

```bash [Terminal]
-v benchkit-runs:/var/www/html/storage/app/runs
```
