BenchKit is a **self-hostable benchmarking playground for Laravel**. You run it as a container on the server you actually care about, click **Start Benchmark**, and it measures how that box performs across four dimensions — then lets you compare runs and share results.

It's two things at once:

- A **benchmarking tool** for figuring out the fastest, best-value hardware to run Laravel on.
- A **playground for learning PHP performance** — flip OPcache, JIT, or worker mode and watch the numbers move.

## Why we built it

"How fast is PHP?" almost always gets answered with a hello-world benchmark — the one workload that doesn't reflect a real application. Those numbers make frameworks and runtimes look dramatically faster or slower than they behave in production, and they've launched a thousand misleading Twitter threads.

BenchKit takes the opposite approach. It measures a **realistic mix** of work, is **honest about what it does and doesn't test**, and discloses the exact configuration behind every number. The goal is numbers you can actually trust — and reproduce.

## What it measures

| Stage | Tool | What it tells you |
| --- | --- | --- |
| Hardware | YABS (Geekbench, fio) | Raw CPU and disk throughput of the box |
| Network | cfspeedtest | Latency/bandwidth from the box to Cloudflare's edge |
| Web server load | oha | Requests/sec + latency for four representative routes |
| PHP database (CRUD) | phpbench | Per-operation timing of Create/Read/Update/Delete |

::note
The web-server load test includes a **simulated I/O route** — the workload where PHP-FPM and FrankenPHP/Octane worker mode converge. It's what lets BenchKit reproduce the *real* performance lesson instead of the hello-world hype. See [Benchmarks & methodology](/docs/benchmarks).
::
