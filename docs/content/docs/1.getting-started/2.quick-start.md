---
title: Quick start
description: Get BenchKit running on any server in one command.
---

BenchKit ships as a container image, so all you need is Docker.

## Run it

```bash [Terminal]
docker run -p 80:8080 \
  -v benchkit-runs:/var/www/html/storage/app/runs \
  serversideup/benchkit-laravel
```

Then open the server in your browser and click **Start Benchmark**.

- `-p 80:8080` maps your host's port 80 to the container's web server (port `8080`).
- `-v benchkit-runs:/var/www/html/storage/app/runs` keeps your **run history** across container restarts. Without it, history lasts only as long as the container.

::tip
Benchmark a VPS the way you'd actually deploy: run BenchKit **on the box itself** so the numbers reflect that hardware, then destroy the container when you're done.
::

## Benchmark FrankenPHP (Octane worker mode)

The same app ships as multiple [image variations](/docs/image-variations). To benchmark FrankenPHP in worker mode, use the `frankenphp` tag and start Octane:

```bash [Terminal]
docker run -p 80:8080 \
  -v benchkit-runs:/var/www/html/storage/app/runs \
  serversideup/benchkit-laravel:frankenphp \
  php artisan octane:start --server=frankenphp --host=0.0.0.0 --port=8080
```

Run it once on `fpm-nginx` and once on `frankenphp`, then open both in **Compare** to see the difference. Results are always labeled with the mode that produced them.
